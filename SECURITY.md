# Security Policy

## Supported versions

Security fixes are applied on the default branch (`master` / `main`) of this repository.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email **[security@codelink.systems](mailto:security@codelink.systems)** with:

- A clear description of the issue
- Steps to reproduce (if possible)
- Impact assessment (if known)
- Any suggested remediation

We aim to acknowledge reports within **3 business days** and to provide a status update within **10 business days**.

## Scope notes

This project may process analytics queries against local/demo datasets and call third-party LLM APIs. Reports related to authentication bypass, injection into SQL tooling, secret exposure, or unsafe deserialization are especially welcome.
